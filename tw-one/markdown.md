# Markdown (опционально)

На раздел понадобится около 10 минут.

**Markdown** — простой язык разметки, который многие технические специалисты используют для создания и редактирования документации. Вы пишете в обычном текстовом редакторе, например vi или Emacs, и добавляете специальные символы для заголовков, полужирного текста, списков и другого оформления.

Вот небольшой технический текст с разметкой Markdown:

```markdown
## bash и ksh

**bash** очень похожа на более старую оболочку **ksh**. Главное
*практическое* различие между ними такое:

* bash знают больше людей, чем ksh, поэтому помощь с bash найти проще.
```

После обработки разметки он выглядит так:

## bash и ksh

**bash** очень похожа на более старую оболочку **ksh**. Главное *практическое* различие между ними такое:

* bash знают больше людей, чем ksh, поэтому помощь с bash найти проще.

---

Парсер Markdown преобразует файлы с разметкой в HTML. Затем браузер показывает получившийся HTML читателю.

Чтобы освоиться с Markdown, пройдите одно из следующих руководств на английском:

- [Markdown Tutorial](https://www.markdowntutorial.com/).
- [Mastering Markdown](https://guides.github.com/features/mastering-markdown/).
